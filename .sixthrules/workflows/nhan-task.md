# Nhận task tiếp theo

1. Đọc `tasks/BOARD.md`, chọn task `TODO` đầu tiên có Người làm là Sixth. Không có thì báo Demi và dừng.
2. Chuyển task sang `DOING`, nêu kế hoạch ngắn.
3. Làm đúng phạm vi file của task.
4. Chạy lint, type-check, build nếu project có.
5. Commit với mã task, chuyển task sang `REVIEW`, ghi một dòng vào cột Ghi chú.
6. Báo Demi: đã xong gì, chưa kiểm tra gì, và nhắc chuyển lượt cho Claude để review.
